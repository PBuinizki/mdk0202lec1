Что такое Bash?

Bash = Bourne-Again Shell

Каламбур: «Bourne Again» звучит как «Born Again» — рождённый заново.

Bourne — фамилия разработчика первого популярного shell для Unix (1978).

Кто он в системе?

Bash — это интерпретатор команд: переводит твой текст в понятные системе команды и возвращает ответ.

🧠 Аналогия: переводчик между тобой и операционной системой.

Bash — это верный пёс 🐕

  • 🐾 Неприхотлив — работает на Linux, macOS, Windows (через WSL)
  • 🐾 Умный — одна команда заменяет десять кликов
  • 🐾 Работящий — обработает 1000 файлов и не пожалуется
  • 🐾 Не всегда красивый — чёрное окно с текстом, и это нормально
⚠️ Хвостиком не виляет. Ошибёшься — холодно ответит: command not found.

Файловая система Linux

В Windows путь: C:\Users\Name\Documents

В Linux корень один — /. Всё висит на нём, как дерево корнями вверх.

Три символа, которые надо запомнить

Символ Что значит Аналогия
/ Корень, начало всего Центр Земли
~ Твоя домашняя папка Твоя комната
.. Уровень выше Выйти в коридор

Навигация: pwd, ls, cd

pwd          # Где я? (Print Working Directory)
ls           # Что тут лежит?
cd /tmp      # Перейти в /tmp
cd ~         # Домой
cd ..        # На шаг назад
cd -         # Вернуться туда, где был только что
💊 cd - — таблетка от «ой, не туда зашёл».

Четыре всадника работы с файлами

Команда Что делает Опасность
mkdir Создать папку Низкая
touch Создать пустой файл Низкая
cp Копировать Средняя
mv Переместить / переименовать Средняя
rm Удалить ВЫСОКАЯ
⚠️ В Linux нет корзины! rm удаляет навсегда.

Файлы на практике

mkdir demo                          # создать папку demo
touch demo/hello.txt                # создать пустой файл
cp demo/hello.txt demo/copy.txt     # скопировать
mv demo/copy.txt demo/renamed.txt   # переименовать
rm demo/hello.txt                   # удалить файл
rm -r demo                          # удалить папку (-r = рекурсивно)

Магия Bash: Tab и история

🗂️ Клавиша Tab — твой второй мозг

ls /e<Tab>            # автоматически станет /etc
cat /etc/pass<Tab>    # автоматически станет /etc/passwd

📜 История команд

Действие Что делает
↑ / ↓ Листать историю
history Показать всю историю
!n Выполнить команду №n
Ctrl + R Поиск по истории
💡 Ctrl+R — привычка с первого дня.

Wildcards (звёздочки) — массовое оружие

ls *.txt          # все .txt файлы в папке
rm photo_*.jpg    # удалить все jpg, начинающиеся с photo_
cp main* /backup/ # скопировать всё, что начинается с main
⭐ Одна звёздочка заменяет сто копипастов.

Три «потока» каждого процесса

Номер Имя Что это
0 stdin Ввод
1 stdout Обычный вывод
2 stderr Вывод ошибок

Перенаправление

echo "Hello" > out.txt      # записать (перезапишет)
echo "World" >> out.txt     # дописать в конец
ls /nonexistent 2> err.txt  # ошибки — в отдельный файл

Конвейер: |

Смысл: вывод левой команды становится вводом правой. 

cat file.txt | grep "error" | wc -l

Перевод на человеческий:

  1. Прочитать файл
  2. Найти строки со словом «error»
  3. Посчитать, сколько их
🎯 Три команды, соединённые в одну строку. Это и есть сила Bash.

Команда Зачем Пример
