Система отступов

Почему все отступы должны быть кратны одному числу

  • ✓ Базовый делитель — обычно 4 или 8 пикселей. Все отступы — его кратные: 8, 16, 24, 32, 48, 64…
  • ✓ Это создаёт визуальный ритм — глаз улавливает закономерность и интерфейс кажется упорядоченным.
  • ✓ Упрощает коммуникацию: вместо «сделай отступ чуть больше» — «поставь 24px».
  • ✓ Масштабируется: одна система работает на мобильных и десктопах.
Правило: если отступ не кратен базовому делителю — его нельзя использовать. Никаких 13px, 17px или 25px.

Композиция: принцип близости

Элементы рядом — воспринимаются как группа. Элементы далеко — как разные вещи

Близко → одна группа ✕ 2

Далеко → просто точки

Закон близости (Гештальт): мозг группирует объекты по расстоянию между ними. Меньше отступа — сильнее связь. Больше отступа — слабее. Управляя отступами, вы управляете смыслом.

Закругления и формула вложенности

Внешнее закругление = внутреннее закругление + отступ

Внутри: 12px
Внешнее (28) = Внутреннее (12) + Отступ (16)
  • ✓ Когда контейнер скруглён, вложенный элемент тоже нужно скруглить — иначе возникает визуальный диссонанс.
  • ✓ Формула гарантирует, что кривые параллельны и смотрятся естественно.
  • ✓ Если внешний радиус меньше внутреннего — кривые «пересекаются» и выглядит это сломанным.
  • ✓ То же касается отступов: padding контейнера = разница между радиусами.

Z-паттерн

Как глаз движется по странице с небольшим количеством контента

  • ✓ 1. Верхний левый угол — логотип, название бренда.
  • ✓ 2. Верхний правый — навигация или кнопка действия (Login, Sign up).
  • ✓ 3. Нижний левый — ключевая информация, заголовок.
  • ✓ 4. Нижний правый — призыв к действию (CTA-кнопка).
Когда применять: лендинги, страницы с минимумом текста, где важны 4 ключевых элемента.

F-паттерн

Как глаз читает страницы с большим количеством текста

  • ✓ Внимание концентрируется на верхней части — там самый важный контент.
  • ✓ Горизонтальные «сканы» становятся короче к низу — пользователь читает меньше.
  • ✓ Левая сторона — strongest: навигация, заголовки, списки.
  • ✓ Правая сторона часто игнорируется — туда ставят второстепенное.
Когда применять: блоги, статьи, каталоги, списки, email-рассылки — везде, где много текстового контента.

Сетки в дизайне

Сетка — это каркас, который организует контент и создаёт ритм

  • ✓ Flexbox — одномерная: элементы в строку или столбец.
  • ✓ Bootstrap Grid — 12-колоночная система с готовыми классами.
  • ✓ CSS Grid — двумерная: строки и колонки одновременно.
  • ✓ Сетка не ограничивает — она направляет.

Flexbox

Одномерная раскладка — элементы в строку или в колонку

  • ✓ Идеален для рядов и колонок: меню, панели кнопок, теги.
  • ✓ justify-content — выравнивание по главной оси.
  • ✓ align-items — по поперечной.
  • ✓ flex-wrap — перенос на новую строку.
  • ✓ gap — отступы между элементами.

Bootstrap Grid

12-колоночная сетка с готовыми классами адаптивности

  • ✓ Каждая строка делится на 12 колонок. Элемент занимает 1–12 колонок.
  • ✓ Классы: col-6 = половина, col-4 = треть, col-3 = четверть.
  • ✓ Адаптивные классы: col-md-6 — на планшете 2 колонки, col-12 — на телефоне в строку.
  • ✓ Gutter — отступ между колонками, обычно 24–30px.

CSS Grid

Двумерная раскладка — строки и колонки одновременно

  • ✓ Полный контроль над строками и колонками одновременно.
  • ✓ grid-template-areas — именованные области для наглядной раскладки.
  • ✓ repeat(auto-fit, minmax(...)) — колонки сами подстраиваются под ширину.
  • ✓ Идеален для целых макетов страниц, а не только компонентов.
Flex vs Grid: Flex — для рядов внутри компонента. Grid — для раскладки всей страницы.

Воздух в дизайне

Пустое пространство — это не пустота. Это инструмент

Плотно

Текст прижат, нет дыхания. Читателю тесно, сложно ориентироваться.

Тесно и дёшево

Воздушно

Отступы дают глазу отдых. Контент читается легко, воспринимается дорого.

Премиально
  • ✓ Воздух разделяет смысловые блоки — работает как принцип близости.
  • ✓ Чем больше воздуха вокруг — тем дороже воспринимается продукт (Apple, luxury-бренды).
  • ✓ Чем плотнее — тем дешевле и «массовее» (маркетплейсы, агрегаторы).
  • ✓ Воздух вокруг важного элемента привлекает внимание — изоляция = фокус.

Психология форм

Форма элемента передаёт настроение ещё до чтения текста

Острые углы

Строгость, надёжность, официальность. Банки, документы, B2B.

Скруглённые

Дружелюбие, современность. Большинство приложений и сервисов.

Капсулы

Мягкость, доступность. Чипы, теги, кнопки соцсетей.

Круг

Общение, человек, игра. Аватары, иконки, FAB-кнопки.

Правило: радиус скругления — это не вкусовщина, а коммуникация. Острый угол = формальность. Мягкий = дружелюбие. Круг — социальность.
